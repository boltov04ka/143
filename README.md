# Сайт клана 143

Статический сайт. Для размещения на Vercel:

1. Загрузите содержимое этой папки в GitHub или импортируйте проект в Vercel.
2. В Vercel выберите Framework Preset: Other.
3. Оставьте Build Command и Output Directory пустыми; корнем проекта должна быть папка с `index.html`.
4. Нажмите Deploy.

`index.html` использует изображения из `assets/`. Сохраняйте эту структуру папок.
